Infrastructure Monitoring & Incident Notifications

A hands-on project exploring infrastructure monitoring and automated incident notifications. AWS EC2 and Terraform provide the cloud environment, while Docker Compose runs monitoring services including Prometheus, Grafana, Uptime Kuma, and n8n. The workflow explores sending monitoring notifications to Telegram. A local incident-summary component was experimental.

Architecture Breakdown

☁️ AWS Infrastructure

AWS EC2 hosts the monitoring and automation platform. Terraform is used to provision and manage the infrastructure.

🐳 Container Layer

Docker Compose deploys and manages Prometheus, Grafana, Uptime Kuma, and n8n services.

📊 Monitoring Layer

Uptime Kuma monitors service availability, Prometheus collects metrics, and Grafana visualizes dashboards.

⚙️ Automation Layer

n8n receives monitoring events and automates the incident response workflow.

Incident Summary (Experimental)

An optional local-model workflow was explored for summarizing incident information. This component is experimental and is not presented as a production service.

📱 Notification Layer

Telegram receives real-time incident alerts and service recovery notifications.
